#  Repositório de Banco de Dados

Bem-vindo ao meu repositório de estudos e projetos práticos voltados para a área de **Banco de Dados**. Aqui concentro atividades, scripts SQL, modelagens e aplicações integradas desenvolvidas ao longo da minha jornada de aprendizado.

---

## Tecnologias Utilizadas

* **MySQL:** Sistema de gerenciamento de banco de dados relacional (SGBD).
* **PHP:** Linguagem back-end utilizada para conexão e manipulação dos dados.
* **JavaScript (JS):** Interatividade e validações no front-end.
* **XAMPP:** Ambiente de servidor local (Apache e MariaDB/MySQL) para testes e execução dos projetos.

---

## 📂 Estrutura do Repositório

> *(Dica: você pode atualizar esta lista conforme for adicionando pastas)*

* `/scripts-sql` — Comandos DDL, DML, consultas (SELECT, JOINs), procedures e triggers.
* `/modelagem` — Diagramas Entidade-Relacionamento (DER) e modelos lógicos/físicos.
* `/projetos-integrados` — Aplicações web conectadas ao banco de dados usando PHP e JS.

---

##  Como executar os projetos localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Mova a pasta do projeto para o diretório `htdocs` dentro da instalação do seu **XAMPP**.
3. Inicie os módulos **Apache** e **MySQL** no painel de controle do XAMPP.
4. Acesse `http://localhost/phpmyadmin` no seu navegador e importe os arquivos `.sql` disponíveis.
5. Abra o projeto no navegador através do endereço `http://localhost/nome-da-pasta`.
